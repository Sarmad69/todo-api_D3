# Todo API — FastAPI + SQLite

A simple RESTful Todo API built with FastAPI, SQLAlchemy, and SQLite as part of my backend development learning roadmap.

This project focuses on learning persistent storage, CRUD operations, SQLAlchemy ORM, FastAPI dependency injection, and clean API design.

## Features

* Create a new todo
* Get all todos
* Get a single todo by ID
* Update an existing todo
* Delete a todo
* SQLite database persistence
* SQLAlchemy ORM integration
* Pydantic request validation
* 404 handling for missing todos
* Interactive Swagger API documentation

## Tech Stack

* Python
* FastAPI
* SQLAlchemy
* SQLite
* Pydantic
* Uvicorn
* uv
